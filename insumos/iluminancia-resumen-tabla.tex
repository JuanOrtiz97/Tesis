Las áreas se conservan tal como fueron exportadas para el cálculo lumínico. La suma se calcula antes de redondear; no se modifica una exportación para forzar coincidencia entre modelos.

El total publicado por DesignBuilder es 253,482 m\textsuperscript{2}; sumar las 19 áreas exportadas a tres decimales produce 253,485 m\textsuperscript{2}. La diferencia de 0,003 m\textsuperscript{2} se mantiene identificada; las filas impresas a dos decimales no son la base de recálculo del total.
