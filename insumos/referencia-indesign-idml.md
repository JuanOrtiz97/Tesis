# Referencia de estructura InDesign

Archivo revisado: `2025-04-18 PRESENTACION TRABAJO FINAL.idml`.

Este archivo se usa como referencia grafica para ajustar la tesis en LaTeX. No se copia contenido del documento; se extraen criterios de diagramacion, color, jerarquia y composicion.

## Criterios extraidos

- Formato original del IDML: 1920 x 1080 pt, composicion horizontal y lectura por doble pagina.
- Paginas enfrentadas activadas (`FacingPages=true`), por lo que las composiciones deben entenderse como spreads.
- Margen base del documento InDesign: 36 pt.
- Tipografias principales detectadas: Bahnschrift, Myriad Pro y Minion Pro. Para la tesis en Overleaf se mantiene una familia sans serif compatible con LaTeX.
- Paleta principal detectada:
  - Verde profundo: `#1B4643`.
  - Verde secundario: `#255954`.
  - Amarillo de portadas/separadores: `#ECF22E`.
  - Blanco: `#FFFFFF`.
  - Negro: `#000000`.
- Jerarquia grafica:
  - Numeros de capitulo grandes.
  - Titulos principales en verde profundo.
  - Pies de imagen discretos.
  - Encabezados limpios con linea horizontal.
  - Composiciones con mucho aire y pocos elementos decorativos.

## Aplicacion en la tesis

- La portada principal usa una composicion grafica tipo libro.
- Luego se deja una pagina blanca.
- Despues se coloca una portada institucional limpia.
- Las portadas de capitulo usan fondo amarillo y numero grande.
- Las paginas interiores usan verde profundo para encabezados, titulos y pies.
- Las figuras, tablas y fuentes deben mantenerse discretas y consistentes.
